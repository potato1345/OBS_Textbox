# Geshiped Animationen (Textbox Studio)

Diese Dateien werden mit dem Plugin ins OBS-Plugin-Data-Verzeichnis
(`data/obs-plugins/textbox-studio/animations/`) installiert.

- `sparkle.webp` — sanfte, transparent twinklende Lichtpunkte (loopend).
- `pulse.webp` — atmende Cyan-Ringe, transparent (loopend).

Verwendung: im Dock bei einer Karte das Feld "Animation" mit dem Dateinamen
(`sparkle.webp` oder `pulse.webp`) oder einem absoluten Pfad setzen. Relative
Namen werden zuerst im eigenen Animations-Ordner (Settings) und dann in diesem
mitgelieferten Ordner gesucht. Formate: webp/gif/png/jpg/webm/mp4/mov.
